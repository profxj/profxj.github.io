PypeIt is an open-source Python package for the semi-automated reduction of
astronomical spectroscopic data. It converts raw two-dimensional spectra into
calibrated, sky-subtracted, one-dimensional spectra with robust error
propagation, and supports a growing list of spectrographs on telescopes such as
Keck, VLT, Gemini, and others. See the [Software](/portfolio/) section for the
project itself.
