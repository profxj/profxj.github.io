**Sea-Meets-the-Stars** is a GitHub organization "devoted to the machine
learning and Bayesian analysis of large datasets of oceanographic data" &mdash;
bringing techniques developed for astronomical surveys to sea-surface
temperature, remote sensing, and in-situ profile data. Representative
repositories:

- **ulmo** &mdash; out-of-distribution detection on sea-surface-temperature data
- **fronts** &mdash; ocean front detection and analysis
- **nenya** &mdash; self-supervised representation learning for SST fields
- **ihop** &mdash; mapping measured intensities to Hydrolight optical properties
- **cugn** &mdash; analysis of the California Underwater Glider Network
- **wrangler** / **remote_sensing** &mdash; tooling to wrangle remote-sensing datasets

- **Org:** [github.com/Sea-Meets-the-Stars](https://github.com/Sea-Meets-the-Stars)
