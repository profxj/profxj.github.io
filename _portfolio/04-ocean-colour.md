**ocean-colour** is a GitHub organization gathering open-source tools for the
analysis of ocean-colour remote-sensing data &mdash; part of my work applying
astronomical data-science methods to oceanography. Repositories include:

- **ocpy** &mdash; general ocean-colour analyses
- **correct-atmosphere** &mdash; atmospheric correction for ocean-colour imagery
- **xqaa** &mdash; retrieval of inherent optical properties (IOPs)
- **IOPtics** / **PAB** &mdash; IOP-algorithm analysis and PACE / BGC-Argo matchups
- **habs** &mdash; harmful algal bloom analyses

- **Org:** [github.com/ocean-colour](https://github.com/ocean-colour)
