**linetools** is an [Astropy](https://www.astropy.org)-affiliated Python package
for working with one-dimensional astronomical spectra. It provides tools for
continuum fitting, equivalent-width and column-density measurements, absorption-
and emission-line identification, and interactive spectral analysis &mdash;
widely used in studies of the intergalactic and circumgalactic medium.

- **Code:** [github.com/linetools/linetools](https://github.com/linetools/linetools)
- **Org:** [github.com/linetools](https://github.com/linetools)

I am a core developer of linetools.
